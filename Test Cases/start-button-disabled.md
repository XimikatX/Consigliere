## Test Case: TC-002

### Test Name
"Start" Button is Disabled When Invalid Player Roles are Entered

### Test Objective
Verify that the "Start" button remains disabled if a user inputs invalid or incomplete player roles.

### Preconditions
- User has initiated a new game from the Home screen.
- User has already entered player nicknames.

### Steps to Execute
1. Open the application.
2. Navigate to the Home screen.
3. Click the "New Game" button.
4. Input player nicknames and click the "Done" button.
5. Input invalid or incomplete player roles (e.g., leaving some roles empty or entering incorrect number of roles).

### Expected Result
- The "Start" button remains disabled and the user cannot proceed to start the game.

### Actual Result
- The game can start only when all players have been assigned their roles properly.
