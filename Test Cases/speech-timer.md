## Test Case: TC-003

### Test Name
Speech Timer Functionality During Game Flow

### Test Objective
Verify that during the game, the user can view and track the speech time using the timer.

### Preconditions
- User has successfully started a new game.
- The Ongoing Game screen is displayed.

### Steps to Execute
1. Start a new game from the Home screen.
2. Observe the timer displayed on the screen.
3. Allow the speech timer to count down.

### Expected Result
- The speech timer is visible and accurately tracks the time elapsed or remaining for the player’s speech turn.

### Actual Result
- Speech timer is visible, countdown is working correctly.
