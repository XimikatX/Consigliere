## Test Case: TC-001

### Test Name
Game Startup Functionality

### Test Objective
Verify that a user can successfully start a new game.

### Preconditions
- User is at the Home screen.

### Steps to Execute
1. Open the application.
2. Navigate to the Home screen.
3. Click the "New Game" button.
4. Input player nicknames and click the "Done" button.
5. Input player roles and click the "Start" button.

### Expected Result
- A new game starts successfully, and the user is taken to the Ongoing Game screen with the inputted players.

### Actual Result
Ongoing Game screen is shown with correct player names, game starts successfully.
